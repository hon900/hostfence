# Maintainers

## Security Maintainer

Named role. The Security Maintainer is the only person who may publish
GitHub Security Advisories, change `SECURITY.md`, or merge patches that
alter default block ranges.

- **hon900** ([@hon900](https://github.com/hon900)) — Lead Security Maintainer

## Core maintainer

- **hon900** ([@hon900](https://github.com/hon900)) — release owner

## How the security role is verified

GitHub shows this assignment on:

1. This file
2. The [security policy](https://github.com/hon900/hostfence/security/policy)
3. [CODEOWNERS](.github/CODEOWNERS) for `SECURITY.md` and `src/`
4. [OpenSSF security insights](.github/security-insights.yml) (`security-contacts`)
